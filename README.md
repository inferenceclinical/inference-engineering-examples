# Inference Engineering examples

Runnable examples for the practical lessons in [Inference Engineering](https://inferencepublic.co.uk/learn/inference-engineering/) from Inference Public.

Each lesson uses a **fictional** public-service scenario and **synthetic** data. Nothing here connects to a real council, resident, supplier or release system. The examples are teaching material, not production release controls.

| Lesson | Folder | What you can run |
|---|---|---|
| 1. The tests pass. Should the release go ahead? | [`ie01-release-gate/`](ie01-release-gate/) | A fictional release-evidence gate, a deliberately weak test suite, an independent policy-derived suite, and eight deliberately broken gates, with predictions frozen before anything ran |

New lessons are added as their own folders.
